# videos

Fábrica de vídeos do canal: guia de estilo, fluxo de produção, plano de edição em dados (v2), validador, render de revisão e scripts de ambiente.

- `fabrica-videos/INDEX.md`: mapa de toda a documentação
- `fabrica-videos/setup/SETUP-WINDOWS.md`: montar o ambiente no Windows, passo a passo
- `graphics/README.md`: gráficos do Remotion (cartão de capítulo, linha de medida, diagrama) como clipes transparentes para o CapCut
- `fabrica-videos/IMPLEMENTATION_REPORT.md`: o que foi implementado, testado e o que ainda não foi

Pendente: o arquivo `industrial-cold-warm-core.cube` (LUT), vídeos de referência completos e a mídia do primeiro episódio. Vídeo e áudio não são versionados.
